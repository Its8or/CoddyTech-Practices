## 📋 Descrição do Desafio

Criar um sistema interativo que rastreie despesas diárias do usuário, permitindo adicionar, visualizar, calcular totais e gerenciar registros de gastos de forma organizada e eficiente.

---

## 🎯 Objetivo

- ✅ Implementar um sistema de rastreamento de despesas com menu interativo
- ✅ Permitir adicionar, visualizar e deletar despesas
- ✅ Calcular o total e média de despesas registradas
- ✅ Praticar lógica de programação com estruturas de controle (while, match/case)
- ✅ Trabalhar com listas e manipulação de dados em Python

---

## 💻 Tecnologias Utilizadas

- **Linguagem:** Python 3.10+ (utiliza match/case)
- **Estruturas:** Listas, While loops, Match/Case statements
- **Conceitos:** Manipulação de dados, entrada/saída, operações aritméticas

---

## 🚀 Como Executar

### Pré-requisitos
- Python 3.10 ou superior instalado

### Instalação
```bash
# Nenhuma dependência externa necessária
# Apenas certifique-se de ter Python 3.10+ instalado
python --version
```

### Uso
```bash
python DailyExpenseTracker.py
```

**Exemplo de interação:**
```
Welcome to the Daily Expense Tracker!

Menu:
1. Add a new expense
2. View all expenses
3. Calculate total and average expense
```

## 📚 O que Aprendi

Este projeto foi fundamental para consolidar conceitos essenciais de Python:

- ✅ **Match/Case (Python 3.10+)** - Estrutura moderna para múltiplas condições
- ✅ **Listas e Operações** - Append, enumeração e iteração
- ✅ **Loops e Controle de Fluxo** - While True e quebra de loops
- ✅ **Entrada/Saída** - Input() e formatação de strings com f-strings
- ✅ **Operações Aritméticas** - Soma, média e manipulação numérica

**Desafios enfrentados:**
- Implementar validação adequada de entrada do usuário
- Estruturar o código de forma clara com o match/case
- Garantir que a lista de despesas persista durante a sessão
