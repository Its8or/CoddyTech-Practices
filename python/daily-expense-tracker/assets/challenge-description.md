
## O Que Comprar

### Dificuldade: Médio

Escreva um programa que receba três entradas (**fornecidas**):

1.   Uma lista de preços
2.  Uma lista de nomes de itens
3.  Um orçamento por item

O programa deve imprimir:

1.  Uma lista de itens que você pode pagar dentro do seu orçamento
2.  Quanto orçamento você precisaria se comprasse todos os itens acessíveis
3.  Quantos itens você não pôde pagar

> Verifique os casos de teste para o formato de saída
