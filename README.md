# 🚀 CoddyTech-Practices

Soluções e projetos desenvolvidos durante minha jornada de aprendizado em programação no [Coddy.tech](https://coddy.tech). Este repositório centraliza desafios práticos, explorações de linguagens e documentação de cada projeto publicado em redes sociais.

## 📚 Sobre

Este é um espaço dedicado a:
- ✅ Documentar soluções de desafios práticos
- ✅ Compartilhar aprendizados e boas práticas
- ✅ Manter histórico de projetos publicados
- ✅ Facilitar consultas futuras e possível reutilização de código

## 🎯 Como Usar Este Repositório

### Para explorar um projeto:
1. Navegue até a pasta da linguagem desejada
2. Abra o `README.md` do projeto para entender a solução
3. Consulte o código-fonte para detalhes de implementação

### Para adicionar um novo projeto:
1. Crie uma pasta com o nome do desafio em kebab-case na linguagem correspondente
2. Adicione o código-fonte (`[NomeArquivo].js` ou `.py`)
3. Crie a pasta `assets/` com `screenshot-code.png` e `challenge-description.md`
5. Atualize este `README.md` com a nova entrada na tabela correspondente
