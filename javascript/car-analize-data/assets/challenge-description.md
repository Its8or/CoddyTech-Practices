Desafio

Fácil

Crie uma função chamada `analyzeCarData` que recebe um objeto JSON como entrada. O objeto contém dados sobre o inventário de uma concessionária de carros onde:

-   as chaves são os modelos dos carros
-   os valores são os preços

A função deve retornar um objeto contendo:

1.  `mostExpensive`: o nome do carro mais caro
2.  `cheapest`: o nome do carro mais barato
3.  `averagePrice`: o preço médio de todos os carros
